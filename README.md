# Terraform CI/CD Project

This project demonstrates Terraform infrastructure code validation using Azure DevOps Pipeline.

## Tools Used
- Terraform
- Azure DevOps Pipelines
- GitHub
- Azure Provider

## Pipeline Steps
1. Install Terraform
2. Check Terraform formatting
3. Initialize Terraform
4. Validate Terraform configuration

## Purpose
To automate Terraform code checks whenever code is pushed to the master branch.
